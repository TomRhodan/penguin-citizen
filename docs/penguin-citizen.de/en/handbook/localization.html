Handbook

    Localization

    Install community-maintained language packs to play Star Citizen in your preferred language.

    Current Status

    The top section shows your currently installed language pack (if any), including:

    • Language name
    • Commit SHA (version identifier)
    • Installation date
    • Update indicator - shows if a newer version is available

    Available Languages

    Below the status, a list of downloadable community language packs is displayed. Each entry shows:

    • Language name and source repository
    • Install button for languages not yet installed
    • Update button when a newer version is available
    • Remove button for installed languages

    Progress is shown during installation and updates.

    Blueprint markers

    Star Citizen hands out blueprints as rewards on certain missions but does not say which ones in the mission text. Penguin Citizen can add that information while installing a translation: the install dialog has an Add blueprint markers option.

    With it enabled, affected missions get

    • a marker in the title - [BP] or [BP?]
    • a block at the end of the description listing the possible blueprints, the reputation required, the faction and the cooldown

    What the markers mean

    [BP] means the mission draws from a blueprint pool for certain. That is not the same as "you are guaranteed this particular blueprint" - which one drops depends on the pool, your reputation rank and the region. [BP?] marks missions where the payout itself is a chance; the percentage in the block states it.

    Where the data comes from

    The mission-to-blueprint mapping is extracted from the game's own files and lives in a separate repository: penguin-citizen-blueprints. Rank, faction and item names are resolved against the translation you installed, so the block appears in the language of your language pack.

    If you see a version notice

    The data always belongs to one specific game build. When you tick the option, Penguin Citizen checks whether data exists for your installed version and reports a mismatch:

    "Blueprint data was built for game version X but Y is installed. Markers may be incomplete."

    That is not an error, it is a heads-up: after a Star Citizen patch it takes a while for the data to catch up. The install still goes through, and missions present in both versions are marked correctly. Only new or renamed missions are missing.

    The markers live in the translation file, not in the game itself. Remove the language pack, or reinstall it without the option, and they are gone. If the blueprint data cannot be reached the translation is still installed - you simply get a notice.
    Penguin Citizen automatically checks for translation updates when you open the Dashboard. If an update is available, a yellow indicator appears on the installation status card, and you can update with a single click.
    Language packs are community-maintained translations, not official CIG translations. The quality and completeness may vary. Remote language information is cached for up to one hour.
