Handbook

    Wine Runners

    Download and manage Wine/Proton runners, DXVK versions, and Wine prefix tools.

    Installed Runners

    The top section lists all Wine/Proton runners currently installed on your system. Each runner shows:

    • Runner name — hover it for the full installation path
    • Size on disk, the Wine version reported by wine --version, and the installation date
    • Origin — the source the build came from (e.g. LUG). Runners installed before version 0.5.14 may have no recorded origin, in which case none is shown.
    • For Proton builds, the detected directory layout (proton or proton-legacy)
    • Whether it is the runner used by the currently active Launch Profile (highlighted)
    • Usage badges — Used by N profiles (hover for the list of profile names) and Fallback if this runner is set as the global Wine Runner Fallback

    These details are loaded after the list itself, so the runner name appears immediately and the detail line follows a moment later.

    The Select button sets a runner for the active profile. Note that the runner is now a per-profile setting — switching here puts the active profile into the dirty state until you commit the change via Update Profile on the Launch page or just keep launching with it.

    The Delete button removes a runner from your system. If the runner is referenced by one or more profiles, the confirmation dialog lists those profiles plus the fallback hint so you don't accidentally break a working setup.

    For day-to-day runner switching, use the runner dropdown directly on the Launch page's profile bar — no roundtrip through this page needed. The Wine Runners page is for installing, deleting, and bulk-managing runners.

    Available Runners

    Browse and download runners from multiple community sources:

    • LUG - Runners curated by the Star Citizen Linux Users Group. This is the primary and recommended source.
    • LUG Experimental - Experimental LUG builds carrying newer patches.
    • RawFox - Specialized Wine builds.
    • Kron4ek - General-purpose Wine builds (32-bit and WOW64 variants are filtered out, as Star Citizen does not need them).

    The + button adds any further GitHub Releases source; each source gets its own tab.

    Each available runner shows its name, source, file size, and release date. The list is sorted newest first. Click Install to download and extract it. A progress bar shows the download status. Runners that are already installed are marked accordingly.

    Use the Refresh button to re-fetch the latest runner lists from GitHub, and Get LUG Sources to re-import the LUG source list. Runner lists are cached for one hour to avoid excessive API calls.

    If you set a GitHub token in Settings, you get higher API rate limits when browsing available runners. This is useful if you frequently check for updates.

    DXVK Management

    DXVK translates DirectX calls to Vulkan, which is essential for running Star Citizen on Linux. This section shows:

    • The currently installed DXVK version
    • Available versions from GitHub releases
    • An Install/Update button to download and deploy the latest version

    DXVK DLLs are automatically placed in the correct Wine prefix locations during installation.

    Manage DXVK from this section only, not via winetricks dxvk. Winetricks would replace the DLLs with its own bundled version while Penguin Citizen keeps reporting the version selected here. That is exactly why dxvk is absent from the repair actions below.

    Prefix Tools

    Star Citizen runs in exactly one Wine prefix — it is your installation path. The header of this section therefore shows the prefix path and a selector for the runner the tools run with. It defaults to the active runner; the choice applies to the tools only and leaves your launch profiles untouched.

    • Winecfg - Opens the Wine configuration dialog. Useful for adjusting DPI scaling, Windows version, and other Wine settings.
    • Wine Shell - Opens a terminal session inside the Wine prefix. Helpful for debugging and manual configuration.
    • Winetricks - Opens the graphical Winetricks menu for this prefix. Requires zenity or kdialog on the system.
    • PowerShell - Installs PowerShell Core into the Wine prefix via winetricks; the RSI Launcher needs it. Once installed, a Refresh button remains available (see the tip below).

    Repair

    One-click actions for known problems. The selection is deliberately small and comes entirely from the LUG knowledge base — these are not generic Windows gaming packages:

    • vcrun2022 - The Visual C++ 2022 runtime. Documented fix for RSI Launcher error 3221225477.
    • Fonts - Reinstalls arial and tahoma, the exact fonts set up during a fresh install. Helps with missing or misrendered text in the RSI Launcher.
    • win11 - Resets the prefix's Windows version.

    A check mark marks actions already applied to the prefix, read from the prefix's winetricks.log. Running them again is still possible and forces a reinstall. While an action runs, a console streams its output live along with an elapsed timer — Winetricks sometimes downloads silently for minutes.

    If installing or updating the RSI Launcher shows a "dotnet48 required" prompt, you can click through it — it does not abort the installation. It comes from LauncherSupport.exe, a .NET 4.8 application shipped with the launcher. The remedy recommended by the LUG is to refresh PowerShell in the prefix.
